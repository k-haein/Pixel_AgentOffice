# 캐릭터 감정·상태 표현 라이브러리

> 작성: 2026-05-13
> 목적: 12×12 도트 캐릭터의 표정 한계를 보완하는 **머리 위 픽셀 아이콘** 시스템

---

## 왜 필요한가

도트 캐릭터(12×12)의 얼굴은 눈 2점뿐이라 표정 변화가 거의 불가능. 대신 **머리 위 픽셀 인디케이터**가 픽셀 게임의 표준 감정 문법.

예: 마인크래프트 빌리저, 스타듀밸리 NPC, RPG Maker 캐릭터들 → 다 머리 위 이모트로 감정 표현.

## 🎨 픽셀 디자인 가이드

각 이모트는 작은 픽셀 그리드 (예: 5×5 ~ 8×8) 로 디자인.

예시 — 💡 (전구):
```
.XXX.
XYYYX
XYYYX
XYYYX
.XXX.
.XX..   (전구 베이스)
```

X = 검은 외곽선
Y = 노란 빛

예시 — Z (졸림):
```
ZZZZ.
...Z.
..Z..
.Z...
ZZZZ.
```

→ 픽셀 그리드 시스템(`drawPixelGrid`)으로 그대로 활용 가능.

| **떨어짐** | y +10px + alpha 1→0 | 💧, 식은땀 |

## 🛠 구현 시 고려 (M5+ 도입 예상)

```ts
// 의사 코드
class EmoteSystem {
  show(character: Container, type: EmoteType, duration?: number) {
    const sprite = drawPixelGrid(this.scene, EMOTES[type].pixels, EMOTES[type].palette, ...)
    sprite.setPosition(character.x, character.y - 30)
    // 애니메이션 적용
    this.applyAnimation(sprite, EMOTES[type].animation)
    // duration 후 자동 제거
    if (duration) setTimeout(() => sprite.destroy(), duration)
  }
}

// 사용 예
emoteSystem.show(mary, 'thinking')       // ⋯ 표시
emoteSystem.show(haewol, 'idea', 2000)   // 💡 2초간
emoteSystem.show(mary, 'sleepy')          // 💤 (상태 변할 때까지)
```
