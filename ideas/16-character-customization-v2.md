> 작성: 2026-05-18 (Day 8 종료 후)
> 출처: 사용자 PC 시각 검증 피드백
> 전제: P1 새 마일스톤. M5-d 성격 시스템과 결합 가능 (MBTI 보류 결정 답한 후)

## 핵심 컨셉

> 기본 캐릭터 3개 (편집자 / 작가 / 커스텀) + 모든 캐릭터를 사용자가 자유롭게 편집 가능.
> 같은 외형도 여러 명 채용 가능 — 이름·지침·모델만 다르면 별개 직원.

## 1. 기본 캐릭터 3종

| 템플릿 | 이모지 | 외형 | 기본 무늬 | 기본 직업 | 비고 |
|---|---|---|---|---|---|
| `editor` (편집자) | ✍️ | 주황 Clawd | 단색 | 편집자 | 기본 — Mary |
| `writer` (작가) | 🪼 | 청록 jellyfish | 점박이 (S/P/G 별·핑크·노랑 하이라이트) | 작가 | 기본 — Haewol |
| `custom` (커스텀) | 🐙 | **그림자 진 문어** | 사용자 선택 | 사용자 입력 | **신규** |

`custom`은 그림자 졌다 = 어두운 회색 베이스 + 사용자가 색 선택 시 *실시간 반영*.

## 2. 채용 모달 — 커스텀 캐릭터 워크플로우

```
[채용 모달]
├─ 템플릿 선택: ✍️ 편집자 / 🪼 작가 / 🐙 커스텀
│
├─ 커스텀 선택 시 ───────────────────
│   ├─ 🎨 색상 팔레트 (12색 픽셀풍)
│   │   · 빨강 / 주황 / 노랑 / 초록 / 청록 / 파랑 / 보라 / 분홍 / 갈색 / 회색 / 흰색 / 검정
│   │   · 클릭 시 우측 미리보기 캐릭터 즉시 색 변화 (그림자 진 문어 → 선택 색 문어)
│   │
│   ├─ ✨ 무늬 선택 (4종)
│   │   · 단색 (기본)
│   │   · 점박이 (작가처럼 산발 하이라이트 — 2~3 픽셀)
│   │   · 그라데이션 (위→아래 색 변화)
│   │   · 줄무늬 (가로 줄)
│   │
│   └─ 미리보기 = 색 + 무늬 실시간 반영
│
├─ 이름 (수정 가능, placeholder: "직업 : 이름")
├─ 직업 (수정 가능)
├─ 지침 — placeholder: "예: 디자이너 : 짧고 명확하게 답변하는 디자이너입니다."
├─ 모델 / 메모리 모델 선택 (기존)
└─ [저장]
```

### 지침 placeholder 형식 — 명시
```
예시 placeholder:
"디자이너 : 미니멀 톤으로 답변합니다."
"개발자 : 코드 예시와 함께 짧게 설명합니다."
"PM : 일정·우선순위 위주로 답합니다."
"마케터 : 후킹 카피와 카테고리로 정리합니다."
```

→ 사용자가 자유롭게 수정 가능. 기본 포맷 학습용.

## 3. 모든 캐릭터 편집 가능 — 연필 버튼

### MemoModal 강화
- 현재: customInstructions + 모델 변경만
- v2 추가:
  - ✏️ 이름 수정
  - ✏️ 직업 수정
  - ✏️ baseInstructions (기존엔 readonly) — 수정 가능

  - 이모지 변경

→ 채용 후에도 캐릭터 정체성 완전 자유 변경.

### 부적절 표현 가드
- 사용자가 "장애인" / "바보" / 혐오 표현 / 성적 표현 입력 시
- 채용 모달 / 메모 모달에서 저장 안 됨 + 안내 메시지
- 또는 저장은 되지만 *LLM 호출 시 system prompt에 가드 추가* → LLM이 "..." 응답
- **결정 필요**: 입력 단계 차단 (저장 X) vs 응답 단계 차단 (입력은 OK, LLM이 "..." 응답)?
  - 입력 차단이 더 깔끔하지만 키워드 매칭 부정확 가능
  - 응답 차단은 LLM의 안전 기능 활용 (더 자연스러움)
  - **추천**: 응답 단계 — system prompt에 "혐오·성적 표현은 '...' 으로 답변" 추가

## 5. 무늬 패턴 정의

### 단색 (Solid)
```
PIXELS = 모두 한 색
```

### 점박이 (Speckled) — 작가 jellyfish 스타일
```
픽셀 90% = 메인 색
픽셀 10% = 하이라이트 (밝은 색)
산발적 배치 (3~5 픽셀)
```

### 그라데이션 (Gradient)
```
위쪽 행 = 메인 색
아래쪽 행 = 메인 색 + 약간 어둡게
중간 = 보간
```

### 줄무늬 (Stripes)
```
홀수 줄 = 메인 색
짝수 줄 = 보조 색 (메인 + 약간 밝음/어둠)
```

각각 캐릭터 픽셀 grid 변형으로 구현.

## 7. 미래 — 커스텀 아이템 카탈로그 (P3+)

### 머리·얼굴
- 🕶 선글라스 (눈 위 검은 픽셀)
- 👓 안경 (눈 위 흰 테)
- 🌾 밀짚모자 (머리 위 노란 픽셀)
- 🤘 뿔 (머리 양쪽 갈색 픽셀)

### 몸
- 👔 셔츠 (몸 픽셀 색 교체) — 색 자유
- 👕 후드 (어깨~머리 덮는 색)

### 책상
- 💻 노트북 (모니터 + 키보드 → 작은 노트북 픽셀로 교체)
- ☕ 머그컵 (책상 위 추가)
- 🌱 작은 화분 (책상 위 추가)

### 의자
- 👑 화려한 의자 (CHAIR 픽셀 → 금색/패턴 의자)
- 🪑 일반 의자 (기본)

각 아이템:
- 상점에서 구매 (가격 = 가상 화폐 또는 단순 무료)
- 캐릭터별로 슬롯에 장착
- 메모 모달에서 변경

## 9. 작업 단계 (Phase)

### Phase 1 — 커스텀 캐릭터 기본 (1~2일)
- `Template = 'custom'` 추가
- 채용 모달에 커스텀 옵션 + 색 12종 팔레트 + 실시간 미리보기
- 그림자 진 문어 픽셀 정의
- store 영속화

### Phase 2 — 모든 캐릭터 자유 편집 (1일)
- MemoModal에 이름·직업·baseInstructions·이모지 수정 추가
- LLM system prompt 변경 반영
- 부적절 표현 가드 (system prompt 추가)

### Phase 3 — 무늬 (1일)
- CharacterPattern 4종 구현
- 캐릭터 픽셀 grid 동적 변형
- 채용 모달 무늬 선택 UI

### Phase 4 — 같은 캐릭터 여러 명 (검증 — 사실 기본 채용 로직이 ID 기반이라 무리 없음)
- UI에서 중복 채용 허용
- 명패에 같은 이모지 중복 표시 OK

### Phase 5 — 미래 커스텀 아이템 (별도 마일스톤 + 상점과 통합)
- 아이템 픽셀 정의 (장기)
- 슬롯 시스템
- 상점에서 구매

## 10. 모호한 점

- **`Template = 'custom'` vs `Template`을 폐기하고 모든 캐릭터를 그냥 커스텀화**?
  - 추천: `Template`은 *프리셋*으로 유지 (편집자/작가 = 빠른 시작 옵션), 커스텀은 *처음부터 사용자가 다 입력*
  - 모든 캐릭터는 채용 후 자유 편집 가능

- **MBTI 페르소나(M 보류 결정)와 통합**?
  - 캐릭터 v2 = 외형·이름·지침
  - MBTI = 성격 (M5-d)
  - 둘이 분리 — 외형 커스텀 후 MBTI 별도 선택
  - 또는 MBTI 선택 시 기본 외형 추천 (예: INTP → 회색 + 안경)

- **부적절 표현 가드 — 입력 차단 vs 응답 차단**?
  - 추천: 응답 차단 (LLM이 알아서 "..." 답)
  - 단점: 사용자가 "장애인" 같은 단어 *맥락에 따라* 정당히 쓸 수도 (편집 작업 등) — 응답 차단이 유연

→ 명령 받을 때 위 모호점 확인 필요 시 사용자에게 물음.
