# 이중 모드 아키텍처 — Solo Office + Team Office

> 작성: 2026-05-12
> 핵심 아이디어: 사용자가 제안 — 같은 사무실 컨셉 안에 **두 가지 사용 모드**를 둔다

---

## 배경 — 두 가지 다른 사용 패턴

### 패턴 1: 페르소나 채팅 (Solo)
- 일반 Claude/ChatGPT 사용자의 대표적 사용 방식
- 예: "편집자" 인격을 부여해 원고 검토, "철학자 칸트" 인격으로 글 피드백
- 기술적으로는 **시스템 프롬프트 + 단일 채팅**
- 멀티 에이전트가 아님

### 패턴 2: 팀 기반 멀티 에이전트
- 본 프로젝트의 Seegene 케이스
- Leader → Workers, 협업, 분배, 검토
- 복잡한 작업을 여러 전문가 협업으로 처리

**→ 머릿속 모델이 완전히 다름. UI도 다르게 가야 자연스러움.**

---

## 추천 구조 — "같은 건물, 다른 층"

```
🏢 PixelAgentOffice
├─ 🛋️ Solo Office (Floor 1, 기본 진입점)
│   ├─ 독립 페르소나들 (각자 책상)
│   ├─ 팀 관계 없음 — 각 에이전트는 자기 일만
│   ├─ 더블클릭 → 1:1 채팅
│   └─ 예시 캐릭터:
│       ✍️ 편집자 / 📚 튜터 / 🧠 칸트 / 🎨 디자이너 / 📰 뉴스 요약가
│
└─ 👔 Team Office (Floor 2, 고급 사용자)
    ├─ Leader + Workers 팀 구조
    ├─ Leader 더블클릭 → 자동 작업 분배
    ├─ Worker끼리 협업, 결과 통합
    └─ 예시:
        Seegene 팀 (nxt-leader + 워커들)
        사용자 정의 팀 (직접 조직)
```

**층 전환**: 좌측 상단 버튼 또는 엘리베이터 픽셀 아이콘 (재미 요소)

---

## 공유 / 분리 정리

### 공유 (shared)
- Phaser 게임 엔진
- 캐릭터 시스템 (Clawd / Human 팩)
- 사무실 레이아웃 원칙 (한 화면, 상단 보스, 클러스터)
- 에이전트 정의 포맷 (팀 관계는 옵션 필드)
- 권한 시스템 (per-agent 도구 권한)
- 채팅 UI 컴포넌트
- 결과 preview 패널

### 분리 (mode-specific)
- **Solo**: 팀 관계 없음, Leader 개념 없음, 1:1 채팅에 집중
- **Team**: 팀 조직도 표시, Leader 분배 UI, 작업 라우팅 시각화

---

## 기술적 단순함 — Solo가 훨씬 쉽다

**Solo 모드 구현 요소**
- Claude API 호출 (시스템 프롬프트 = 페르소나 정의)
- 채팅 히스토리 저장
- 결과 렌더링 (Artifact/Canvas 스타일 preview)
- 권한 검사 (도구 호출 시)

**Team 모드 추가 구현 요소** (Solo 위에)
- Leader → Worker 메시지 라우팅
- 작업 분배 로직 (LLM 자율 또는 규칙 기반)
- 워커 결과 수집 및 통합
- 부서/팀 관계 시각화
- 진행 상태 트래킹

→ **Phase 1.1 = Solo만**, **Phase 2 = Team 추가**가 자연스러움.

## 사용자 경험 시나리오

### Solo 모드 예시 — 일반인 사용자
1. 앱 실행 → 1층 사무실, 빈 책상 몇 개
2. "+ 새 직원 채용" 클릭
3. 캐릭터 갤러리 → 안경 Clawd 선택
4. 이름: "마리", 역할: "내 글 편집자", 페르소나 설명 입력
5. 책상 자동 배정 → 마리가 자리에 앉음
6. 마리 더블클릭 → 채팅 열림 → 원고 붙여넣기
7. 마리의 답변이 길면 → 우측 preview 패널에 크게 표시

### Team 모드 예시 — 개발자/고급
1. 2층으로 엘리베이터 이동
2. Seegene 팀 임포트 → 16명의 Seegene 에이전트가 자리잡음
3. nxt-leader 더블클릭 → "이 파일들 변환해줘" 명령
4. nxt-leader가 nxt-layout, nxt-grid 등에게 자동 분배
5. 각 워커 책상에서 일하는 애니메이션
6. 결과가 모이면 nxt-reviewer가 검수
7. 통합 결과를 사용자에게 보여줌
