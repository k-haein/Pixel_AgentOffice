# AI 개념 지도 — 내가 배운 것들 (성장형)

> 시작: 2026-07-02
> 목적: AI 기초 지식이 없어서, 대화 중 배운 개념을 **쉬운 말 + 비유**로 모아두는 사전.
> 사용법: 새 개념을 배울 때마다 해당 그룹에 한 줄씩 추가. "이게 뭐였더라?" 할 때 여기부터 열기.
> 범례: ✅ 배움 · ⭐ 내 프로젝트에 중요 · 🔵 알아두면 좋음(고급)

---

## 🧵 하나로 꿰는 비유 (전화 비유)

> AI = 똑똑한 **전문가(사람)** / API = 그 사람한테 거는 **직통 전화**
> 나는 **만능 전화기(AI SDK)** 로 전문가에게 전화해서, 도구를 주고받으며(도구 호출 + 에이전트 루프)
> 일을 시키고, 필요하면 다른 전문가에게 넘긴다(위임). 전문가는 여러 명(멀티모델) 중 골라 쓴다.

## 그룹 1. 기본 재료 (AI를 이루는 조각)

| 개념 | 쉬운 말 | 표시 | 내 프로젝트 연결 |
|---|---|---|---|
| 모델 | AI 전문가 본체 (Claude/GPT/Gemini) | ✅ | 직원의 두뇌 |
| 토큰 | AI가 글자를 세는 단위(단어 조각). **비용·한도 기준** | ⭐ | 토큰 보드, 비용 한도 |
| 컨텍스트 윈도우 | AI가 **한 번에 기억하는 양** (전화 한 통의 기억 범위) | ⭐ | 메모리, 밤 모드 |
| 프롬프트 | AI한테 주는 지시/질문 | ✅ | 채팅 입력 |
| 시스템 프롬프트 | 캐릭터 **성격·역할** 배경 지침 | ✅ | **메모지**(기본+커스텀 지침) |

## 그룹 2. 모델에 말 거는 방식

| 개념 | 쉬운 말 | 표시 |
|---|---|---|
| API | AI에게 거는 직통 전화 | ✅ |
| 멀티모델 | 전문가 여러 명 골라 쓰기 (전화번호부) | ⭐ |
| AI SDK | 통일된 연락 부품 (만능 전화기). **서비스 아님, 내 앱 부품** | ⭐ |
| 스트리밍 | 답을 **한 글자씩 실시간**으로 받기 (타자 치듯) | ⭐ |
| temperature(온도) | 답변의 **창의성 다이얼** (낮음=정확, 높음=자유) | 🔵 |
| 멀티모달 | 글자뿐 아니라 **이미지·PDF**도 이해 | 🔵 |
| BYOK | 자기 API 키로 직접 결제 | ✅ |

## 그룹 3. "에이전트"를 만드는 것 (핵심)

| 개념 | 쉬운 말 | 표시 |
|---|---|---|
| tool-calling (도구 호출) | AI가 "도구 좀 줘"라고 **요청**하는 능력 | ⭐ |
| 에이전트 루프 | 도구 주고받기 **반복** (일하는 과정 전체) | ⭐ |
| 에이전트 | 루프+도구로 **스스로 일하는** AI (대답만 하는 챗봇과 구분) | ⭐ |
| ReAct | "추론→행동→추론→행동" = 에이전트 루프의 **학술 이름** | 🔵 |
| MCP | 도구·데이터를 **표준 규격**으로 AI에 꽂기 (USB 같은 것) | 🔵 |

## 그룹 4. 여러 에이전트 (2층 협업)

| 개념 | 쉬운 말 | 표시 |
|---|---|---|
| 멀티 에이전트 | AI 여러 명이 팀으로 | ⭐ |
| 오케스트레이터/워커 | 팀장이 분배 → 팀원이 실행 | ⭐ |
| 위임(delegation) | 팀장이 팀원에게 일 넘기고 **결과 돌려받음** | ⭐ |
| 핸드오프(handoff) | 대화를 다른 에이전트에게 **통째로 넘김**(안 돌려받음) | 🔵 |
| 랄프 루프 | 큰 작업을 **끝날 때까지 통째로 재시도**(바깥 루프) | 🔵 |

**루프 2종 관계** (겹쳐 있음):
```
[랄프 루프]  ← 바깥: "다 될 때까지 계속 다시 시켜" (거대 작업용, 지금 불필요)
   └ [에이전트 루프]  ← 안쪽: 이번 한 번의 도구 주고받기 (필수 기본)
        └ [tool-calling]  ← 도구 한 번 요청
```

## 그룹 5. 기억 (Memory) — AI의 약점 다루기

| 개념 | 쉬운 말 | 표시 |
|---|---|---|
| 컨텍스트 한계 | AI는 대화방 밖을 **기억 못 함**(매번 리셋) | ⭐ |
| 메모리 | 기억을 **파일에 적어뒀다 다시 먹여주기** | ⭐ |
| 압축(compaction) | 기억이 꽉 차면 **요약해서** 자리 만들기 | ⭐ |
| RAG | 질문에 맞는 **자료를 검색해 AI에게 붙여주기**(문서 기반 답변) | 🔵 |
| 임베딩/벡터 | 글을 **의미로 검색**하려 숫자로 바꾸기(RAG 부품) | 🔵 |

## 그룹 6. 품질·안전

| 개념 | 쉬운 말 | 표시 |
|---|---|---|
| 환각(hallucination) | AI가 **그럴듯하게 지어냄**(틀린 걸 자신 있게) | ⭐ |

| 파인튜닝 | 모델 자체를 **재훈련** (나는 **안 씀** — 프롬프트로 충분) | 🔵 |
