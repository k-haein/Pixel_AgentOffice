# 직급 시스템 — 캐릭터 입장 + 옵션 선택형

> 작성: 2026-05-13 (재설계)
> 핵심 변화: 자동 진급 ❌ → **캐릭터가 자기 입장에서 진급 요청** + 사용자가 진급 조건 모드 선택

---

## 1. 왜 직급?

- 캐릭터에 **시간 투자 보상** (RPG 레벨업 같은 느낌)
- 사용자가 "내 직원을 키워가는" 감각
- 진급 시 시각적 변화 → 사무실이 살아있는 조직처럼 보임
- SNS 공유 콘텐츠 (스크린샷에 "Mary 부장 승진!" 같은 알림)

**중요 원칙**: 직원은 **도구가 아닌 캐릭터**. 진급은 **사용자가 캐릭터를 부려서가 아니라, 캐릭터가 사용자에게 *요청*해서** 이루어진다.

---

## 2. 진급 조건 — 모드 선택형 (설정)

사용자가 4가지 모드 중 선택. 기본값 ⏰ 시간형.

| 모드 | 조건 | 추천 |
|---|---|---|
| 📊 **정량형** | 대화 N회 + 메모 M회 갱신 | 게임적, 측정 명확 |
| ⭐ **정성형** | 칭찬 / 👍 버튼 N회 이상 | 진짜 성과 반영 |
| ⏰ **시간형** ⭐ | 채용 후 일정 기간 (1개월/3개월/6개월) | 가장 현실적 (기본) |
| 🔀 **혼합형** | 위 셋 중 N개 충족 | 균형 |
| 🛑 **수동만** | 자동 제안 OFF, 사용자가 직접 | 통제 ↑ |

### 모드별 기본 조건값 (직급별)

**📊 정량형 기본값**:

| 직급 | 누적 대화 | 누적 메모 갱신 |
|---|---|---|
| 사원 | 5 | - |
| 대리 | 50 | 1 |
| 과장 | 150 | 5 |
| 부장 | 400 | 15 |
| 이사 | 800 | 30 |
| 사장 | 2000 | 100 |

**⭐ 정성형 기본값**:

| 직급 | 칭찬/👍 받은 횟수 |
|---|---|
| 사원 | 1 |
| 대리 | 5 |
| 과장 | 15 |
| 부장 | 40 |
| 이사 | 100 |

**⏰ 시간형 기본값**:

| 직급 | 채용 후 경과 |
|---|---|
| 사원 | 3일 |
| 대리 | 2주 |
| 과장 | 1개월 |
| 부장 | 3개월 |
| 이사 | 6개월 |
| 사장 | 1년 |

## 3. 정성형 측정 — 칭찬 카운트 방법

### 방법 A: 명시적 버튼 (M4-b)

각 에이전트 응답 아래 작은 버튼:
```
[Mary]: 편집본 v2 만들었어요.
        [👍 좋아요]  [👎 다시]
```

👍 클릭마다 칭찬 +1.

### 방법 B: 키워드 감지

사용자 메시지에서 다음 키워드 발견 시 +1:
- "잘했어", "고마워", "최고", "완벽", "👍", "👏", "❤️"
- 부정 키워드 ("못하네", "다시") → -1 또는 미반영

### 방법 C: 클로드 자체 판단 (고급)

매 응답 후 Haiku에 물어봄: "이 사용자 메시지가 긍정적 피드백인가? (yes/no)" → yes면 +1.
비용 약간 ↑.

기본 권장: **A + B 조합**.

## 4. 디자인 — 캐릭터가 진급 요청

### 흐름

```
[조건 도달]
   ↓
[캐릭터 머리 위 💬 또는 🙋 이모트] (몇 초간)
   ↓
[모달 자동 열림 — 캐릭터 voice]
```

### 모달 시안

```
┌──────────────────────────────────────┐
│ [Mary 픽셀 캐릭터, 머리 위 💬]         │
│                                       │
│ "사장님... 잠시 시간 괜찮으세요?       │
│  제가 입사한 지도 어느덧 두 달이네요.  │
│  혹시 진급 평가가 있을까요?"           │
│                                       │
│  현재: ✏️ 대리                         │
│  희망: 📊 과장                         │
│                                       │
│  📈 그간 성과:                         │
│  • 대화 127회                         │
│  • 메모 12회 갱신                      │
│  • 칭찬 8회                           │
│  • 입사일: 2026-03-15 (2개월)         │
│                                       │
│  [😊 진급 ] [🤔 아직 일러] [⏭ 다음에] │
└──────────────────────────────────────┘
```

### 사용자 응답 시 캐릭터 반응

| 응답 | 캐릭터 반응 |
|---|---|
| 😊 **진급 승인** | 콘페티 ✨ + 동료들 ♥ / 👏 / 🎉 이모트 + 시각 변화 |
| 🤔 **아직 일러** | 시무룩 표정 (1초) → "알겠습니다, 더 열심히 할게요" → 다시 일함 |
| ⏭ **다음에** | "네 알겠습니다 😊" → 1~2주 후 다시 제안 |

## 5. 캐릭터별 voice variation

기본 지침/성격이 진급 요청 톤 결정:

| 캐릭터 / 성격 | 진급 요청 톤 |
|---|---|
| **Mary** (꼼꼼한 편집자) | "사장님, 잠시 시간 괜찮으세요? 인사평가 가능할까요?" |
| **Haewol** (해파리 작가) | "별빛이 한 번 더 차오를 때마다 시간이 흐르네요... 저도 한 단계 위로 헤엄칠 수 있을까요?" |
| **칸트** (철학자) | "사장님, 보편적 정의에 따라 제 노동의 가치를 평가받고 싶습니다." |
| 😎 **게으름** | "어... 진급? 그러면 일이 더 많아지는 건 아니죠?" |
| 🔥 **야망형** | "사장님! 저, 진급할 자격 있다고 생각합니다!" |
| 😳 **수줍음** | "..." [말 없이 머리 위 ? 만 띄움] |
| ☕ **간식러** | "사장님, 진급하면 간식비 늘어나나요?" |
| 😴 **잠꾸러기** | "음냐... 진급... 시켜주시면 더 열심히... 잘게요..." |

→ 같은 직원이라도 **성격이 다르면 다르게 요청** 가능. 다양성 ↑.

### 톤 템플릿 (커스텀 지침에 추가 가능)

사용자가 직접 진급 요청 톤 커스텀 가능:

```
[Mary 메모지 → 커스텀 지침]
- 비유는 최대 2개까지
- 반말 금지
- 진급 요청은 정중하게  ← NEW
```

또는 "진급 요청 안 함" 옵션으로 끄기.

## 6. 연봉 협상 시즌 모드 (대안)

분기/연간으로 묶어서 한꺼번에 처리:

```
[1월 1일 = 인사평가 시즌]
   ↓
[조건 충족한 직원들이 한꺼번에 요청]
   ↓
[큰 모달: "이번 시즌 진급 후보 N명"]
   - ✏️ Mary → 📊 과장 [승인/보류]
   - 🪼 Haewol → ✏️ 대리 [승인/보류]
   - ...
   [모두 처리]
```

→ "회사 인사평가 시즌" 게임적 이벤트.

설정에서 토글: "건마다 제안" / "시즌마다 일괄" / "둘 다".

## 7. 초기 직급 설정 (채용 시)

채용 모달에 진급 트랙 옵션:

```
┌─ 새 직원 채용 ──────────────────┐
│                                   │
│ 캐릭터: ✍️ Mary 템플릿              │
│ 이름:   [Mary           ]           │
│ 역할:   [편집자          ]          │
│                                   │
│ 초기 직급:                          │
│   ● 🌱 알바부터 (기본)              │
│   ○ 📋 사원                         │
│   ○ ✏️ 대리                          │
│   ○ 📊 과장 (경력직 시작)            │
│   ○ 📈 부장                         │
│   ○ ⚙️ 직접 입력                     │
│                                   │
│ 진급 방식:                          │
│   ○ 📊 정량                         │
│   ○ ⭐ 정성                         │
│   ● ⏰ 시간 (기본)                   │
│   ○ 🔀 혼합 / ○ 🛑 수동             │
│                                   │
│         [채용 완료]                 │
└───────────────────────────────────┘
```

## 8. 진급 시 시각적 변화

| 직급 | 캐릭터 외형 | 책상·환경 |
|---|---|---|
| 알바 | 기본 Clawd | 기본 책상 |
| 사원 | 작은 명찰 추가 | 기본 + 명패 색 ↑ |
| 대리 | 안경 옵션 등장 | 명패 색 ↑ |
| 과장 | 넥타이/리본 픽셀 | 의자 좀 더 좋아짐 |
| 부장 | 작은 배지 | 책상 색 ↑ + 화분 |
| 이사 | 정장 톤 변경 | 책상 ↑ + 와인병 |
| 사장 | 골든 안경 / 액세서리 | 큰 책상 + 카펫 |
| 회장 | 황금 후광 (subtle) | 코너 자리 + 트로피 |
| 레전드 | 반짝이는 외곽선 | 동상? 명예의 전당 |

## 9. 직급 ↔ 시스템 영향

### Phase 1 — 순수 시각
- 진급 = 명패 / 외모 / 책상 변경만

### Phase 2+ — 선택적 기능 차이
- 부장+ : 다른 워커에게 일 분배 가능 (Leader 권한)
- 사장+ : 모든 직원의 메모 열람 가능
- 회장+ : 새 직원 채용 자동 제안

설정으로 ON/OFF 가능 (기능적 차이 원치 않는 사용자도 있음).

## 10. 데이터 구조

```ts
type EmployeeProgress = {
  rank: string             // '과장' or 커스텀
  rankAuto: string         // 자동 계산된 직급 (오버라이드 추적용)
  promotionMode: 'quantitative' | 'qualitative' | 'time' | 'mixed' | 'off'
  totalMessages: number
  totalMemoryUpdates: number
  totalPraises: number
  hiredDate: Date
  promotionHistory: {
    fromRank: string
    toRank: string
    date: Date
    decidedBy: 'user' | 'season'
  }[]
  pendingProposal?: {
    proposedRank: string
    proposedAt: Date
    snoozedUntil?: Date  // "다음에" 했을 때 다음 제안 시점
  }
}
```

저장: `data/employees/<id>/progress.json`

## 13. 결정 요약

| 항목 | 결정 |
|---|---|
| 진급 방식 | **제안 + 승인** (자동 진급 X) |
| 제안 주체 | **캐릭터가 자기 입장에서 요청** (사용자 시점 X) |
| 진급 조건 모드 | 정량/정성/시간/혼합/수동 — 사용자 선택 |
| 기본 모드 | ⏰ 시간형 (가장 현실적) |
| 기본 진급 트랙 | 알바 → 사원 → 대리 → 과장 → 부장 → 이사 → 사장 → 회장 → 레전드 |
| 초기 직급 | 사용자가 채용 시 자유 선택 (기본 알바) |
| 톤 | 캐릭터 성격/지침에 따라 다르게 |
| 정성형 측정 | 👍 버튼 + 키워드 감지 (기본 권장) |
| 거절 처리 | "다음에" → 1~2주 후 재제안, "아직 일러" → 시무룩 |
| 시즌 모드 | 옵션 (분기/연 단위 일괄 평가) |
| 기능적 영향 | Phase 1엔 순수 시각, Phase 2+에 선택적 |
