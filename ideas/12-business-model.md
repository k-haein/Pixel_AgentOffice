# 비즈니스 모델 결정 — LLM 제공 방식

> 작성: 2026-05-14
> 트리거: 사용자 깨달음 "이거 다른 사람들도 결제 등록해야 해?"
> 핵심 인식: BYOK 모델의 본질적 진입 장벽 + 대안 옵션 정리

---

## 1. 출발점

사용자의 원래 비전:
> "이미 Claude를 쓰는 사람한테 UI 인터페이스를 무료로 제공해주고 싶었다."

이 비전의 **현실적 한계 발견** (claude-code-guide 에이전트 조사):

| 시도 | 결과 |
|---|---|
| Claude.ai Pro 구독으로 외부 앱 인증 | ❌ 불가능 (Anthropic ToS 명시적 금지) |
| Claude Code SDK OAuth 활용 | ❌ 제3자 앱은 ToS 위반 |
| Claude Agent SDK | API 키만 지원, OAuth 없음 |

→ **"이미 구독자 = 우리 앱도 무료"** 모델 자체가 Anthropic 정책상 불가능.

## 2. 일반 사용자의 진입 장벽 분석

BYOK(Bring Your Own Key) 모델의 현실:

### Anthropic Claude
- **선불 충전식**: $5 이상 충전 필요
- 카드 등록 + 충전 = 두 단계 부담
- 장점: 절대 한도 넘김 X (선불이라 안전)
- 단점: 일반 사용자에게 진입 부담

### Google Gemini (2024년 정책 변화)
- 신규 Google Cloud 프로젝트 → 기본 quota = 0
- 키 발급은 되지만 사용 권한 없음
- 해결: ① 카드 등록 ② 기존 프로젝트 사용
- 결제 등록만 하면 무료 한도 안에선 ₩0 청구
- 다만 일반 사용자에게도 "카드 등록 강제"의 인식 부담

→ **두 옵션 다 카드 등록 사실상 강제**. 사용자 깨달음:
> "다른 사람들도 이렇게 등록해야 해?"

## 3. 대안 옵션 4가지

### A. BYOK 유지 (현재 구조)
- 사용자: API 키 발급 + 결제 본인 책임
- 우리: 비용 0, 책임 0
- **장점**: 운영 단순, 법적 책임 X
- **단점**: 일반 사용자 진입 장벽 ↑
- **적합**: 개발자/얼리어답터/포트폴리오용
- **시간**: 0 (이미 완성)

### B. 백엔드 만들기 (SaaS)
- 우리 서버 → Anthropic/Google에 결제
- 사용자: 무료 또는 월 $X 구독
- 사용자 인증 + 일일 제한 + 광고/유료 옵션
- **장점**: 진정한 "무료 다운로드 + 즉시 사용"
- **단점**: 서버 운영비, 사용자 인증, DB, 트래픽 관리, 결제 시스템
- **적합**: 본격 SaaS 사업
- **시간**: 며칠~몇 주

### C. 다중 LLM Provider 지원
- BYOK 유지하되 LLM 선택지 확장
- **Groq (Llama)**: 카드 등록 없이 무료 (분당 30회, 일일 14,400회)
- **Cohere Trial**: 카드 X (제한적)
- **Ollama 로컬**: PC에서 직접 (인터넷 X, 무료, PC 사양 필요)
- 사용자가 본인 상황에 맞게 선택
- **장점**: 진짜 "다운로드만 받으면 무료" 가능
- **단점**: 무료 옵션은 품질 ↓ (한국어/페르소나)
- **적합**: 현재 단계에서 진입 장벽 가장 효과적 완화
- **시간**: Groq 5분, Ollama 2~3시간

### D. 데모 모드
- API 없이 mock 응답 (랜덤 미리 정해진 답)
- "둘러보기" 가능, 실제 LLM 없음
- **장점**: 비용 0, 카드 X, 즉시 가능
- **단점**: 실제 가치 없음, 학습/시연용
- **적합**: SNS 홍보 영상, 첫 인상
- **시간**: 30분

|---|---|---|---|---|---|
| **Groq** (Llama) | ❌ X | 30 / 14,400 | ⭐⭐ | ⭐⭐ | 카드 없이 진정한 무료 |

| **Claude** Haiku | ⭕ 충전 필수 | - (종량제) | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 빠르고 저렴 |
| **Claude** Sonnet | ⭕ 충전 필수 | - (종량제) | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 우리 앱 컨셉 최적 |
| **Claude** Opus | ⭕ 충전 필수 | - (종량제) | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 최고 성능, 비쌈 |
| **Ollama** (로컬) | ❌ X | 무제한 | ⭐⭐ ~ ⭐⭐⭐⭐ | 모델 따라 다름 | PC 사양 필요 |

→ **한국어/페르소나 최적**: Claude
→ **균형**: Gemini Flash (카드 등록 후)
