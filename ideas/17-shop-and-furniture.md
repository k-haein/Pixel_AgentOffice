## 1. 상점 UI

### 트리거
- topbar에 `🛍 상점` 버튼 추가 (`+ 채용` / `⚙` 옆)
- 또는 사무실 안 floating 버튼 (좌하단?)

### 상점 모달
```
[🛍 상점]
├─ 카테고리 탭: 가구 / 장식 / 캐릭터 아이템(P3+)
│
├─ 가구 그리드 (카드 형식)
│   ├─ 🪴 화분 (소형) — 무료 (이미 보유)
│   ├─ 🪴 화분 (대형) — $X
│   ├─ 📚 책장 (3단) — 무료
│   ├─ 📚 책장 (5단, 큰) — $X
│   ├─ 🥤 자판기 (음료) — 무료
│   ├─ ☕ 커피머신 — $X
│   ├─ 🍽 탕비실 테이블 — $X
│   ├─ 📅 캘린더 (벽) — $X
│   ├─ 🌿 큰 식물 (코너용) — $X
│   ├─ 🛋 소파 (휴게 공간) — $X
│   └─ ...
│
├─ 미리보기 (선택 시 사무실 어디 배치할지 표시)
├─ [구매 / 배치]
└─ [닫기]
```

### 보유한 가구 = 사무실에 자동 배치
- 기본 4종 (화분·책장·자판기·시계)은 이미 P1에 기본 제공 (`D 가구 Lv1` 작업으로 도입됨)
- 상점에서 산 가구는 *사용자가 위치 선택* 후 배치

## 2. 배치 시스템

### 드래그앤드롭 배치
- 상점에서 가구 클릭 → 사무실 영역에 가구 미리보기 (반투명) 떠오름
- 마우스 드래그로 위치 선택 → 클릭으로 확정
- ESC = 취소

### 충돌 검증
- 책상·자리·다른 가구와 겹치면 **빨강 경계** 표시 + 확정 불가
- 가능한 위치 = **녹색 경계** + 확정 가능

### 그리드 스냅 (선택)
- 픽셀 그리드 (28×28 — 현재 사무실 grid와 동일)에 스냅
- 자연스러운 정렬

### 재배치
- 기존 가구 우클릭 → "이동 / 삭제 / 회전" 메뉴
- 이동 모드 진입 (B-3 자리 이동과 유사 UX)

## 4. 가격 / 화폐 시스템 (결정 필요)

### 옵션 A — 가상 화폐 (게임 진행 보상)
- 채용 / 채팅 / 진급 등 진행 시 화폐 획득
- 상점에서 소비
- 게임 메커니즘 강화

### 옵션 B — 단순 잠금 해제 (보유 없음)
- 사용자 진행 단계 따라 카탈로그 잠금 해제
- 채용 N명 도달 시 → 신규 가구 잠금 해제
- 화폐 시스템 부담 X

### 옵션 C — 전부 무료 처음부터
- 모든 가구 처음부터 무료
- 단순한 UX, 사용자 자유도 ↑
- 게임성 ↓

**추천**: **옵션 B (잠금 해제)** — 진행 보상으로 동기 + 화폐 복잡도 X

→ 명령 시 사용자 확인 필요.

## 5. 사무실 영역 구조와 통합

`ideas/15-pc-validation-feedback.md` §16~18의 사무실 박스 구조:

```
┌────────────────────────────────┐
│   [창문 풍경 + 날씨]                  │
├────────────────────────────────┤
│   [벽 — 시계·토큰보드 액자]            │
├────────────────────────────────┤
│   사무실 전체                       │
│   · 사장석                         │
│   · 팀 영역                        │
│   · 가구 배치 영역 (이 안에 가구 둠)   │
└────────────────────────────────┘
```

가구 배치는 **사무실 영역 안**으로 제한. 벽·창문 영역엔 액자/캘린더만.

## 6. 미래 — 사무실 테마 팩 (P3+)

- **현대 사무실** (기본)
- **클래식** (나무·갈색·앤티크)
- **우주** (어두운 배경 + 별 + 우주선 가구)
- **카페** (커피 색·따뜻한 톤)
- **공장** (회색·산업)

테마 = 사무실 전체 색 팔레트 + 기본 가구 스킨 한꺼번에 변경.

→ Lv2 작업으로 분리.

## 7. 작업 단계

### Phase 1 — 가구 크기 키우기 + 위치 조정 (0.5일)
- `D Lv1` 가구 4종 (화분/책장/자판기/시계) 픽셀 크기 확대
- 사무실 영역 안에 배치 (벽 침범 X)

### Phase 2 — 상점 모달 + 기본 카탈로그 (1.5일)
- 상점 모달 UI
- 카탈로그 데이터 (10종 정도)
- 잠금 해제 로직 (옵션 B 선택 시) 또는 단순 무료 (옵션 C)
- 보유 가구 store 영속화

### Phase 3 — 배치 시스템 (1일)
- 가구 클릭 후 드래그 → 위치 선택 → 확정
- 충돌 검증
- 기존 가구 우클릭 (이동/삭제)

### Phase 4 — 추가 가구 + 시각 폴리시 (1일)
- 카탈로그 확장
- 가구별 픽셀 정의 (10~20종)
- 배치 후 시각 검증

### Phase 5 (미래) — 테마 팩 + 커스텀 아이템 (P3+ 별도 마일스톤)

## 8. 모호한 점 (명령 받기 전 확인)

- **상점 트리거 위치**: topbar `🛍` vs 사무실 안 floating?
- **화폐 시스템**: A 가상 화폐 / B 잠금 해제 / C 전부 무료
- **현재 가구(D Lv1)와 통합**: 이미 자동 배치된 화분/책장/자판기/시계 → 사용자가 *위치 자유 변경* 가능하게? 또는 기본 위치 고정?
- **충돌 검증 강도**: 책상과 안 겹침 — 명백 / 다른 가구와 안 겹침 — 명백 / 자리 영역 침범 — 어느 정도까지 허용?
- **회전 가능 여부**: 책상은 회전 가능(B-4). 가구도 회전? — 첫 단계엔 회전 X 권장
