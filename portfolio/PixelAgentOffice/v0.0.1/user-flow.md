## 1. 채용 플로우 (HireModal)

```mermaid
flowchart TD
  A[+ 채용 클릭] --> B[채용 모달 열림]
  B --> C{캐릭터 템플릿 선택}
  C -->|Mary 편집자| D[이름·역할·지침·외형<br/>자동 채움]
  C -->|Haewol 작가| D
  C -->|Cody 개발자| D
  C -->|커스텀 문어| E[빈 칸 + 외형 직접 설정]
  D --> F[MBTI 선택 - 선택사항]
  E --> F
  F --> G[대화 모델 선택]
  G --> H{선택 모델의 API 키 있음?}
  H -->|없음| H1[모델 비활성 + 빨간 안내<br/>+ ⚙ 설정 열기 버튼]
  H1 --> S[설정 모달 중첩<br/>§4]
  S -->|키 등록 후 닫기| G2[채용 모달 입력 그대로 유지]
  G2 --> I
  H -->|있음| I[채용 완료 클릭]
  I --> J{이름·역할 입력됨?}
  J -->|빈칸| J1[빨간 강조 + 중첩 알림 모달]
  J1 --> I
  J -->|OK| K[자동 자리 배치<br/>직급 자격 따라 멤버/리더]
  K --> L[사무실에 캐릭터 등장]
```

**포인트**: 키 없을 때 설정을 열어도 **채용 모달이 닫히지 않고 입력이 보존**됨 (v0.0.1 버그 수정). 알림은 `window.alert`이 아닌 디자인된 중첩 모달.

## 2. 채팅 플로우 (감정 시스템)

```mermaid
flowchart TD
  A[캐릭터 더블클릭<br/>또는 말풍선 클릭] --> B[우측 하단 채팅창]
  B --> C[메시지 입력 → 전송]
  C --> D[작업 중 표시 …]
  D --> E{LLM 응답}
  E -->|성공| F["본문에서 [emotion:xxx]<br/>태그 파싱·제거"]
  F --> G[머리 위 감정 이모지<br/>5초 표시]
  G --> H[기본 감정으로 복귀<br/>idleEmotion]
  E -->|Rate limit / 에러| I[친절 한글 에러<br/>raw URL 노출 X]
  E -->|중단 클릭| J[AbortController로 취소]
  B --> K[채팅창 닫아도<br/>이력 보존 - 영속화]
```

**system prompt 구성**: 기본 지침 + 커스텀 지침 + MBTI 페르소나 + 감정 태그 지침 + `🟡`메모리(계획) → LLM 전송.

## 3. 사무실 인터랙션 (자리·책상·가구)

```mermaid
flowchart TD
  A[캐릭터 우클릭] --> B[컨텍스트 메뉴]
  B --> C[자리 이동 - 드래그앤드롭]
  B --> D[책상 회전 - front/right/left]
  B --> E[메모지 열기 → §5]
  C --> C1{대상 자리 자격?}
  C1 -->|리더=과장↑ / 사장석=사장↑| C2[이동 OK]
  C1 -->|자격 부족| C3[빨간 표시 + 차단]

  F[가구 우클릭] --> G[가구 메뉴]
  G --> G1[🚚 옮기기 - ghost preview]
  G --> G2[🗑 이 가구 삭제]
  G --> G3[🧹 전체 가구 삭제]

  H[🛍 상점 열기] --> I[가구 카탈로그<br/>픽셀 미리보기]
  I --> J[배치 클릭 → 모달 닫힘]
  J --> K[클릭 위치에 가구 배치<br/>ghost 따라다님]
  I --> L[감정 미리보기 열기<br/>12종 캔버스]
```

## 4. 설정 플로우 (API 키 · 중첩)

```mermaid
flowchart TD
  A[⚙ 설정 클릭<br/>또는 채용 모달에서 열기] --> B[설정 모달<br/>채용 위에 중첩 가능]
  B --> C[Google / Anthropic 키 입력]
  C --> D[저장 → OS 키체인 암호화]
  D --> E[저장됨 배지]
  B --> F[기본 모델 · 메모리 모델]
  B --> G[일일 한도 USD]
  B --> H[사용량 상세 표<br/>모델별 RPM 막대]
  B --> I[backdrop 드래그해도<br/>안 닫힘 - mousedown 기준]
```

**중첩**: 채용 모달에서 설정을 열면 설정이 zIndex 위로 떠서 중첩 표시 → 키 등록 후 닫으면 채용 입력 유지 (v0.0.1 수정).
