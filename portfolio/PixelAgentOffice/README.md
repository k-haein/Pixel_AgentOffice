## 🎯 30초 요약

PixelAgentOffice는 AI 에이전트 관리를 **"Two Point Hospital + The Sims"** 류 게임 메커니즘으로 풀어낸 데스크톱 앱입니다.

- 🐙 픽셀 캐릭터(Mary 편집자 / Haewol 작가 / Cody 개발자 / 커스텀)를 **직원으로 채용**
- ✏️ 이름·역할·**MBTI 16종 페르소나**·외형·모델을 시각적으로 지정
- 💬 더블클릭으로 채팅 → 응답에 따라 머리 위 **감정 이모지(12종)** 실시간 변화
- 🛍 상점에서 가구 구매 → 드래그/배치로 **나만의 사무실 꾸미기**
- 📺 사장석 뒤 **토큰 보드** + 시간대 5단계 변화
- 🌙 토큰 소진 시 **강제 야간** (시그니처 폴리시)
- 📦 설치 없는 **portable `.exe`** 로 배포 → 외부 테스터 실사용 피드백 수집 중

## 💡 해결하려는 문제

AI 에이전트는 강력하지만 일반 사용자에겐 **진입 장벽이 높습니다** (YAML/JSON 정의, 터미널, 추상적 오케스트레이션). 그런데도 많은 사람이 ChatGPT/Claude에서 "페르소나 채팅"(편집자·칸트·작가)을 일상적으로 씁니다. → **그 행동을 게임형 워크스페이스로** 옮긴 게 이 프로젝트입니다.

| 기존 도구 | PixelAgentOffice |
|---|---|
| 에이전트 정의 = 코드/설정 | **캐릭터 선택 + 이름 + MBTI** |
| 상태 모니터링 = 로그 | **사무실 둘러보기 + 감정 이모지** |
| 에러 = 빨간 메시지 | **직원이 시무룩 / 친절 한글 안내** |

## 🔍 기획 과정에서 자랑스러운 순간

1. **제약이 결정을 명확하게** — "배포 자동화 필요" → Python 탈락 → Electron 채택
2. **사용자 인사이트가 아키텍처를 단순화** — "동생은 페르소나 채팅 쓴다" → 이중 모드 → Phase 1 단순화
3. **에러를 폴리시로 격상** — 토큰 고갈 → 강제 야간 시그니처
4. **재미를 개성으로** — 12종 감정 이모지 + MBTI 16종 페르소나 (Day 12)
5. **실배포로 검증 진입** — portable EXE v0.0.1 → 외부 테스터 피드백 사이클
6. **정직한 상태 추적** — 완성/부분구현/계획을 구분하고 미완 기능을 명시 (PRD §4.2)
