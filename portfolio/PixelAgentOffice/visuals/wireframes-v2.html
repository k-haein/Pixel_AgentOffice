👤 페르소나 & 핵심 시나리오

와이어프레임을 보기 전에 누가 / 어떤 상황에서 쓰는지.

🎯 Primary: 페르소나 채팅 사용자

  • 작가/학생/디자이너/마케터
  • 이미 ChatGPT·Claude 앱에서 시스템 프롬프트 사용 중
  • 페인: 페르소나마다 채팅창 분리 안 됨, 매번 복붙
  • 기대: "내 글쓰기 도우미 Mary"가 일관되게 답하길
  • 기술 수준: 코드 X, GUI만

⚙️ Secondary: AI 얼리어답터 / 개발자

  • API 키 사용 익숙, 여러 모델 비교
  • 페인: 자기 멀티 에이전트 시각화 도구 없음
  • 기대: 자기 프로젝트 에이전트를 시각화 (Phase 2)
  • 기술 수준: 코드 작성 가능
핵심 사용자 여정 (Journey 1 — 신규)
  • 1. .exe 더블클릭 → 사무실 등장 (Mary, Haewol 기본 2명)
  • 2. ⚙ 설정 → LLM 선택 → API 키 입력
  • 3. 💬 말풍선 클릭 → 첫 대화 → "오, 진짜 답하네!"
  • 4. 📝 메모지 → 커스텀 지침 추가 → 톤 변화 확인
  • 5. "내가 직원을 키운다" 감각 → 애착 형성
