# 토큰 보드 + 사무실 생활 — 시그니처 기능

> 작성: 2026-05-12
> 핵심 아이디어: 사용자가 제안 — 단순 도구가 아닌 "관찰하고 싶어지는 사무실"
> 차별화 요소: 다른 어떤 AI 도구에도 없는 폴리시

---

## 컨셉

> 토큰 사용량을 단순한 숫자로 보여주지 않는다. **사무실의 생활 리듬**으로 표현한다.
> 토큰 다 쓰면 직원들이 퇴근하고, 충전되면 다시 출근한다.

---

## 4가지 핵심 요소

### 1. 토큰 보드 (Token Board)

**위치**: Leader 책상 뒤편 벽에 큰 모니터/현황판

**표시 정보**:
- 오늘 사용량 / 이번 달 사용량
- 남은 예산 (사용자가 설정한 한도 대비)
- 다음 회복 시각 (rate limit reset 또는 다음 결제일)
- 모델별 사용 분포 (Opus / Sonnet / Haiku)
- 작은 막대그래프 (시간대별 사용 패턴)

**비주얼 스타일**:
- 픽셀풍 LED 게시판 느낌
- 깜빡이는 숫자
- 빨강/노랑/초록 신호등 (예산 위험도 표시)
  - 🟢 0–60% 사용
  - 🟡 60–85% 사용
  - 🔴 85–100% 사용

**클릭 시**: 상세 사용 내역 (어떤 에이전트가 얼마나 썼는지)

---

### 2. 토큰 고갈 시 직원 반응 ⭐ 시그니처 기능

토큰이 한도에 도달하면:
1. 모든 컴퓨터 모니터 지직 → 검은 화면
2. 캐릭터들이 **각자 성격대로** 반응
3. 사무실 분위기 전환 (조명 어두워짐 등)

**캐릭터 성격 속성 (예시)**:

| 성격 | 토큰 고갈 시 반응 |
|---|---|
| 😎 게으름 (lazy) | "앗싸~ 퇴근!" 의자 뒤로 기대고 신문 펼침 |
| 😢 성실함 (diligent) | 시무룩, 책상에 엎드림 |
| 😴 잠꾸러기 (sleepy) | 그대로 잠, Z 표시 떠오름 |
| ☕ 간식러 (snack) | 자판기로 가서 커피 / 과자 |
| 🎮 게이머 (gamer) | 핸드폰 게임, 책상 위 컵 휘청 |
| 📞 수다쟁이 (chatty) | 옆 캐릭터에게 말 걸기 |
| 🚬 휴식러 (chill) | 창가에 가서 풍경 봄 |
| 📚 공부벌레 (nerd) | 책 펴서 읽기 |
| 🐱 멍 (zoned) | 허공 응시 |
| 💃 들떠있음 (cheerful) | 음악 듣고 들썩 |

→ **캐릭터 정의에 `personality` 필드 추가**. 사용자가 채용 시 선택 가능.
→ 같은 외형이라도 성격 다르면 다르게 동작 = 캐릭터 다양성 ↑↑

---

### 3. 창밖 시간대 변화 (Day/Night Cycle)

**5단계**:
- 🌅 **아침** (06–11): 밝은 하늘, 부드러운 햇살
- ☀️ **점심** (11–15): 푸른 하늘, 환함
- 🌇 **노을** (15–18): 오렌지·핑크 그라데이션
- 🌆 **저녁** (18–21): 보라색·어두운 파랑
- 🌃 **밤** (21–06): 검은 하늘, 별·달, 멀리 빌딩 불빛

**구동 방식 옵션** (둘 다 적용 가능):
- **(A) 실제 시간 연동** — 사용자 PC 시간에 따라 자연스럽게 변함
- **(B) 토큰 사이클 연동** — 토큰 풀일 때 = 아침, 고갈 시 = 강제 밤
- **(C) 혼합** — 평소엔 실제 시간, 토큰 고갈 시 즉시 밤 모드

**추천: (C) 혼합** — 가장 직관적 + 토큰 고갈을 명확히 시각화

**부가 효과**:
- 점심 시간 (12시) → 일부 캐릭터가 도시락 / 자판기로 이동
- 저녁 (19시) → 일부 캐릭터 퇴근 인사 후 사라짐
- 새벽 → 야근 캐릭터만 남음 (졸음 표정)

---

### 4. 토큰 회복 시 부활 애니메이션

토큰이 회복되거나 새 한도로 리셋되면:
1. 사무실 조명 켜짐 (어두움 → 밝음 페이드인)
2. 컴퓨터 모니터 켜짐 (지직 효과음 → 화면 켜짐)
3. 캐릭터들이 기지개 (애니메이션) → 자리로 복귀
4. 타자 치는 애니메이션 재개
5. 토큰 보드 숫자 새로 깜빡임

**효과**: "회복 = 새 시작" 느낌. 사용자가 다시 작업할 동기 부여.

## 기술적 구현 메모

### 토큰 추적
- Anthropic API 응답에 `usage.input_tokens`, `usage.output_tokens` 포함
- 매 호출 후 누적 → 로컬 SQLite에 저장
- 일/월 단위 집계
- Rate limit 정보는 응답 헤더 또는 별도 endpoint

### 한도 관리
- 사용자 설정: 일일 / 월별 / 누적 예산
- 호출 전 checkBudget() → 초과 시 차단 + UI 트리거
- 차단 동작은 설정으로 변경 가능 (block / warn-only / ignore)

### 시간대 시스템
- 실제 시간: `new Date().getHours()` 기반
- 30분~1시간 간격으로 트랜지션 (부드럽게)
- Phaser에서 카메라 색조 / 배경 그라데이션으로 구현

### 캐릭터 성격 시스템
```ts
type Personality =
  | 'lazy' | 'diligent' | 'sleepy' | 'snack'
  | 'gamer' | 'chatty' | 'chill' | 'nerd' | 'zoned' | 'cheerful';

type Employee = {
  // 기존 필드들...
  personality: Personality;
  reactions: {
    onTokenDepleted: () => Animation;  // 성격별 정의
    onLunch: () => Animation;
    onWorkResume: () => Animation;
  };
};
```

각 성격은 미리 정의된 애니메이션 시퀀스를 가짐. 캐릭터 스프라이트 시트에 해당 프레임들 포함.

## SNS / 마케팅 임팩트

이 기능들이 만드는 콘텐츠:
- **15초 영상**: 토큰 고갈 → 직원들 우당탕 → 보고 웃음
- **타임랩스**: 하루 동안 사무실 풍경 변화
- **GIF**: 특정 캐릭터의 시그니처 반응

→ 사용자가 자기 사무실을 자랑하게 됨 → 자연 홍보
→ "Two Point AI Office" 같은 별명이 붙을 수도

## 단계적 도입 — 어디서 추가?

**기존 로드맵에 끼워 넣기:**

| Phase | 기능 |
|---|---|
| 1.1 | Phaser + 기본 캐릭터 |
| 1.2 | 채용 모달 (+ 성격 선택 추가) |
| 1.3 | 책상 드래그 |
| 1.4 | LLM 연결 + **토큰 보드 (기본)** + 비용 한도 |
| 1.5 | 결과 preview 패널 |
| 1.6 | 채팅 히스토리, 메모리 |
| **1.7** | **🎨 시간대 변화 + 토큰 고갈 반응 (시그니처)** |
| 2.0+ | Team Office, Seegene 임포트 |

→ 1.7로 따로 빼서 **출시 직전 폴리시 라운드**로. Solo 모드 핵심 기능이 다 끝난 뒤 임팩트 극대화.
